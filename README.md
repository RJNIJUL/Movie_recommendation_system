# 🎬 Movie Recommendation System

A content-based Movie Recommendation System built using Python and Machine Learning. It recommends similar movies based on genres, keywords, and plot descriptions.

## 🚀 Features

* Movie recommendations based on similarity
* Text processing using TF-IDF
* Cosine similarity to find similar movies
* Similarity scores for recommendations
* Handles invalid movie titles

## 🛠️ Technologies Used

* Python
* Pandas and NumPy
* Scikit-learn
* Google Colab

## 📊 Dataset

TMDB 5000 Movie Dataset from Kaggle:

* `tmdb_5000_movies.csv`
* `tmdb_5000_credits.csv`

## ⚙️ How It Works

1. Load and clean movie data.
2. Combine genres, keywords, and overviews.
3. Convert text into numerical vectors using TF-IDF.
4. Calculate cosine similarity between movies.
5. Recommend the top 5 similar movies.

## ▶️ How to Run

1. Download the notebook from this repository.
2. Open it in [Google Colab](https://colab.research.google.com/).
3. Upload the two dataset CSV files when prompted.
4. Run the notebook cells in order.
5. Enter a movie title to get recommendations.
